# 🐾 Лапки — сайт приюта для животных

Курсовой проект по дисциплине «Серверная веб-разработка».
Полнофункциональный сайт на собственном backend-фреймворке (PHP + MySQL, паттерн MVC).

## Возможности

**Публичная часть**
- Главная страница с подборкой питомцев и статей
- Каталог питомцев с фильтром по виду (🐱/🐶/🐇)
- Детальная карточка питомца с настоящим фото
- Раздел статей и детальная страница статьи (с автором)
- Калькулятор суточной нормы корма (расчёт по параметрам)
- Форма обратной связи с сохранением в БД
- Страница HTTP-заголовков (демонстрация get_headers)

**Админ-панель** (роль admin)
- Вход по логину/паролю (сессии, password_verify)
- Дашборд со статистикой
- CRUD питомцев: таблица, пагинация по 10, сортировка
- CRUD статей: добавление, редактирование, удаление
- Просмотр обращений из формы

## Структура проекта

```
lapki/                        # корень сайта (DocumentRoot)
├── index.php                 # фронт-контроллер (роутинг)
├── .htaccess                 # перенаправление для Apache
├── router.php                # роутер для встроенного PHP-сервера
├── styles/styles.css         # стили
├── uploads/                  # фотографии питомцев
├── database.sql              # дамп БД (таблицы + тестовые данные)
├── src/                      # серверный код (закрыт от прямого доступа)
│   ├── .htaccess             #   ↳ запрет HTTP-доступа к коду
│   ├── routes.php            #   таблица маршрутов
│   ├── settings.php          #   настройки подключения к БД
│   └── MyProject/
│       ├── Controllers/      #   контроллеры
│       ├── Models/           #   ActiveRecord-сущности
│       ├── Services/         #   Db (PDO), Auth (сессии)
│       ├── View/             #   компонент рендеринга шаблонов
│       └── Exceptions/       #   исключения
└── templates/                # шаблоны представления (закрыт от прямого доступа)
    ├── .htaccess
    ├── header.php, footer.php
    ├── main/, pets/, articles/, feedback/, calculator/, admin/, errors/
```

## Запуск локально

**Вариант 1 — XAMPP / OpenServer / хостинг (Apache + PHP + MySQL):**
1. Импортировать database.sql в phpMyAdmin (создаст БД lapki).
2. При необходимости поправить логин/пароль БД в src/settings.php.
3. Поместить всё содержимое папки проекта в корневую папку сайта (htdocs, public_html или www — название зависит от хостинга).
4. Открыть сайт в браузере.

**Вариант 2 — встроенный сервер PHP (быстрая проверка):**
```bash
# из корня проекта
php -S localhost:8000 router.php
```
Откройте http://localhost:8000

## Безопасность

Папки src/ и templates/ содержат .htaccess с правилом Require all denied —
прямой доступ к исходному коду из браузера запрещён. К файлам можно обратиться
только из фронт-контроллера (index.php) через PHP.

## Соответствие лабораторным работам

- Лаба 1 (форма + HTTP): /feedback (POST + БД), /headers (get_headers).
- Лаба 2 (записная книжка): CRUD питомцев в админке с пагинацией и сортировкой.
- Лаба 3 (фреймворк, ДЗ3-4-5): весь сайт на MVC, /articles с автором,
  динамический title, демо-роуты /hello/$name и /bye/$name.
- Доп. функционал: калькулятор нормы корма, CRUD статей под админом.
